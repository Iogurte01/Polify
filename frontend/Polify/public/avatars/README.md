# Avatares de Perfil

Esta pasta contém as imagens de avatar pré-determinadas para os usuários do Polify.

## Estrutura

- `avatar1.png` - Avatar Padrão
- `avatar2.png` - Aventureiro
- `avatar3.png` - Gamer
- `avatar4.png` - Artista
- `avatar5.png` - Tech
- `avatar6.png` - Natureza
- `avatar7.png` - Esportes
- `avatar8.png` - Música
- `avatar9.png` - Cinema
- `avatar10.png` - Viagem
- `avatar11.png` - Comida
- `avatar12.png` - Livros
- `default.png` - Avatar de fallback (caso alguma imagem não carregue)

## Especificações

- **Formato**: PNG ou JPG
- **Tamanho recomendado**: 200x200 pixels
- **Proporção**: Quadrado (1:1)
- **Tamanho máximo**: 500KB

## Como adicionar novos avatares

1. Adicione as imagens nesta pasta com os nomes especificados acima
2. Se quiser adicionar novos avatares, atualize o arquivo `src/src/app/data/mockData.ts` adicionando novos itens ao array `profileAvatars`

## Nota

As imagens devem ser apropriadas para todos os públicos e seguir as diretrizes da plataforma Polify.
